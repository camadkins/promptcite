# PromptCite help

These files ship with PromptCite so your AI agent can answer questions about
it without going online. The installer copies them to `~/.promptcite/help/`,
and they always match the version you installed. Ask your agent things like
"how do I use /receipt for a project that took three sessions?" or "why does
verify say INVALID?", and it reads the answer from here.

- `using-receipt.md`: what `/receipt` does, every mode, and the usual workflow
- `troubleshooting.md`: when something doesn't show up or doesn't work

Full docs live in the repo at the tag you installed:
`https://github.com/camadkins/promptcite/tree/v<version>`. The installed version
is in `~/.promptcite/help/VERSION`.
